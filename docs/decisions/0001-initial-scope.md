# Decision 0001 — Initial Scope

**Date:** 2026-09-04  
**Status:** Accepted

## Decision

Start with a personal ₹1,00,000 account using Indian NSE cash equities and liquid ETFs, positional/swing trading, no leverage, and no futures/options. Build a custom Python research and risk framework. Add Zerodha execution only after historical validation and paper/shadow trading.

## Rationale

This scope limits complexity, reduces early operational and derivatives risk, and allows the data, backtesting, sizing, and reconciliation foundations to be validated before live execution.

## Consequences

The initial return objective is not a required monthly quota. The first implementation milestone focuses on reproducibility and deterministic risk controls rather than return optimization.
